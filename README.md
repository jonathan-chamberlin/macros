# Macros

AutoHotkey macros for Windows productivity. All scripts are launched via `main.ahk`, which runs automatically on Windows startup.

| Trigger | Action |
|---------|--------|
| `Win+1` | Open Next Actions in Comet |
| `Win+2` | Open Calendar in Comet |
| `Win+3` | Open In Tray in Comet |
| `Win+4` | Open Second Brain in Comet |
| `Win+5` | Explorer: .claude + Downloads + Repos for Git |
| `p` x3 (within 1s) | Types `commit and push` + Ctrl+Enter |
| `l` x4 (within 1s) | Types `git pull origin main` + Enter |
| `Shift+Left` | Previous tab (Comet only) |
| `Shift+Right` | Next tab (Comet only) |
| `jc` + space/enter | Jonathan Chamberlin |
| `eee` | jcham17x@gmail.com |
| `;;date` | Today's date (MM/dd/yy) |
| `Ctrl+C` (no selection) | Copies entire current line |

## Setup

1. Install [AutoHotkey v2](https://www.autohotkey.com/)
2. Double-click `main.ahk` to run (starts all scripts)
