# Macros

Hammerspoon macros for macOS productivity. All scripts are launched via `mac/main.lua`.

| Trigger | Action |
|---------|--------|
| `Option+1` | Open Next Actions in Comet |
| `Option+2` | Open Calendar in Comet |
| `Option+3` | Open In Tray in Comet |
| `Option+4` | Open Second Brain in Comet |
| `Option+5` | Finder: .claude + Downloads + Repos |
| `Option+6` | Open GitHub Repositories in Comet |
| `p` x4 (within 1s) | Types `commit and push` + Ctrl+Enter |
| `l` x4 (within 1s) | Types `git pull origin main` + Enter |
| `Right Option+[` | Previous tab |
| `Right Option+]` | Next tab |
| `Right Cmd+[` | Move tab left |
| `Right Cmd+]` | Move tab right |
| `jc` + space/enter | Jonathan Chamberlin |
| `eee` | jcham17x@gmail.com |
| `;;date` | Today's date (MM/dd/yy) |
| `Cmd+C` (no selection) | Copies entire current line |

## Setup

1. Install [Hammerspoon](https://www.hammerspoon.org/)
2. Symlink: `ln -s /path/to/macros/mac/main.lua ~/.hammerspoon/init.lua`

Windows macros (AutoHotkey v2) are available in the `windows/` folder.
