# Macros

AutoHotkey macros for Windows productivity.

## Notion Hotkeys

Opens Notion pages in Comet browser. Launches Comet if not already running.

| Hotkey | Page |
|--------|------|
| `Win+1` | Next Actions |
| `Win+2` | Calendar |
| `Win+3` | In Tray |
| `Win+4` | Second Brain |

### Setup

1. Install [AutoHotkey v2](https://www.autohotkey.com/)
2. Double-click `notion-hotkeys.ahk` to run
